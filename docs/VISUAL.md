## 2. REKOMENDASI DIFERENSIASI VISUAL

### A. Palet Warna — Ganti Rohanunya

Dusun Kita = nuansa **senja tropis** (bukan pagi cerah seperti negerikomen).

```
ROOFS (atap):
  Negeri Komen: #C4502F (merah bata terang)
  Dusun Kita:   #8B3A2E (merah bata gelap, lebih tanah) + #D4762A (oranye senja)

WALLS (dinding):
  Negeri Komen: #F3E8D2 (krem terang)
  Dusun Kita:   #E8D4B0 (krem hangat) + #C9B790 (coklat kayu)

Background:
  Negeri Komen: hijau sawah cerah
  Dusun Kita:   hijau gelap + ungu senja (#3A4A35 → #5C4A5E gradient)
```

## 3. KONSEP KONTEN (Reels IG)

### A. Format Episode Harian (19:00 WIB)

**Struktur 30 detik:**

```
0-5s    : Hook visual (screenshot peta dusun dari atas)
5-15s   : Pak RT ngomong (voiceover atau text overlay)
          "Hari ke-N di Dusun Kita. Kemarin X warga baru guyub masuk."
15-20s  : Tampilkan warga baru (nama + warna rumah)
20-25s  : Tantangan/quest hari ini
25-30s  : CTA: "Komen: NAMA, BATA <warna>, TEMBOK <warna>"
```

### B. Jenis Konten Serial

| Jenis | Tujuan | Frekuensi | Contoh |
|---|---|---|---|
| **Episode update** | akuisisi warga | harian 19:00 | "Hari ke-7: 57 warga, 3 saung, 2 warung" |
| **Perkenalan warga** | FOMO + rasa memiliki | dalam episode | "Selamat datang @budi123, rumah bata merah di blok 3" |
| **Tantangan komunitas** | engagement | 2-3x/minggu | "Pilih nama gang: A) Mawar B) Melati C) Kenanga" |
| **Event musim** | milestone | mingguan | "Pesta panen Dusun Kita — malam ini 19:00" |
| **Story harian** | top-up engagement | harian | screenshot peta + teks "hari ini di dusun" |
| **Live YouTube** | retention 24/7 | harian | kamera tetap di peta, warga keliling |
| **Behind the scenes** | relatable | mingguan | "cara Pak RT bangun saung dari 0" |

### C. CTA Wajib Seragam (parser kenali)

```
Komen: NAMA, BATA <warna>, TEMBOK <warna>
Contoh: Budi, bata merah, tembok biru
```

### D. Beda dengan Negeri Komen
