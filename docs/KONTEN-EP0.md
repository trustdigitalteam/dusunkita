# Reels Pertama Dusun Kita — Script & Panduan Produksi

## Konsep
**Episode 0: "Dusun Kita Dibuka"** — pengumuman resmi. Pak RT membuka dusun, ajak warga pertama datang.

## State saat Reels
- Day 1
- 0 warga (kosong)
- 2 bangunan: Pos Ronda + Warung
- 0 follower
- Goal: Bangun Balai Dusun (100 Bata)

---

## Script Video (30 detik)

### Shot 1 (0-5s) — Hook
**Visual:** Screenshot peta Dusun Kita dari atas. Kosong. Hanya Pos Ronda + Warung di tengah. Palet senja tropis.

**Text overlay:**
```
DUSUN KITA DIBUKA 🏘️
Hari ke-1 · 0 warga
```

**Voiceover Pak RT:**
"Assalamualaikum. Saya Pak RT. Dusun Kita resmi dibuka hari ini."

### Shot 2 (5-12s) — Penjelasan
**Visual:** Zoom ke Pos Ronda + Warung. Tampilkan nama bangunan.

**Text overlay:**
```
Mulai dari 0:
✅ Pos Ronda
✅ Warung
❌ Belum ada warga
```

**Voiceover Pak RT:**
"Sejauh mata memandang, cuma pos ronda sama warung. Belum ada yang tinggal. Dusun ini butuh warga."

### Shot 3 (12-20s) — Cara Gabung
**Visual:** Animasi teks cara gabung. Sederhana, besar, mudah dibaca.

**Text overlay:**
```
CARA JADI WARGA:
1. Follow @dusunkita.id
2. Komen di video ini:
   NAMA, BATA <warna>, TEMBOK <warna>
   
Contoh: Budi, bata merah, tembok biru
```

**Voiceover Pak RT:**
"Cara jadi warga? Gampang. Follow akun ini, komen nama dan warna rumah kamu di video ini. Besok rumah kamu langsung muncul di peta."

### Shot 4 (20-25s) — Goal
**Visual:** Zoom ke lahan kosong di tengah dusun (lokasi balai).

**Text overlay:**
```
GOAL: BANGUN BALAI DUSUN
Target: 100 Bata
```

**Voiceover Pak RT:**
"Target kita: bangun balai dusun. Butuh 100 Bata. Warga yang traktir Bata otomatis bantu bangun dusun."

### Shot 5 (25-30s) — CTA + Outro
**Visual:** Logo Dusun Kita (genteng + kelapa + senja). Peta dari atas zoom out.

**Text overlay:**
```
Komen sekarang:
NAMA, BATA <warna>, TEMBOK <warna>

@dusunkita.id
dusunkita.vercel.app
```

**Voiceover Pak RT:**
"Yuk, jadi warga pertama Dusun Kita. Komen sekarang. Rumah kamu nunggu."

## Panduan Produksi

### Visual
1. **Screenshot peta** dari https://dusunkita.vercel.app/ (zoom ke tengah, kasih lihat Pos Ronda + Warung)
2. **Edit di CapCut/Premiere** — pan zoom, text overlay, transisi halus
3. **Warna text**: putih dengan shadow hitam (kontras di palet senja)
4. **Font**: sistemui atau font tebal (Inter/Poppins)

### Audio
- **Voiceover**: rekam sendiri pakai suara natural, tidak terlalu formal
- **BGM**: ambience kampung (suara alam, tidak ada musik) — bisa ambil dari web
- **SFX**: pop sound saat text muncul

### Format
- **Durasi**: 30 detik
- **Ratio**: 9:16 (vertical reels)
- **Resolusi**: 1080x1920
- **FPS**: 30

### Waktu Posting
- **19:00 WIB** (sesuai jadwal cron)
- Setelah posting, cron 19:30 otomatis scrape komen
